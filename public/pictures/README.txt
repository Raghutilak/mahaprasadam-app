This folder is where the "Available Sweets" screen (Alternate Screens tab)
looks for each sweet's photo.

Add one photo per sweet, named EXACTLY after the sweet, in this folder:

  Peda.jpg
  Sandesh.jpg
  Rasagulla.jpg
  Rasamalai.jpg
  Sweet Samosa.jpg
  Cake.jpg
  Ladoo.jpg

Notes:
- .jpg, .jpeg, .png, and .webp all work — the app tries each extension in
  that order for a given sweet name, so you don't need to tell it which
  one you used.
- The name must match the sweet's name in the app exactly, including the
  space in "Sweet Samosa.jpg".
- If a sweet's photo is missing (not added yet, wrong filename, etc.), the
  screen shows a plain sweet-icon tile in its place instead of a broken
  image — nothing breaks, it just won't have a photo yet.
- No code changes or rebuild needed to add/replace a photo — just drop the
  file in here (or into the deployed site's /pictures/ folder) and refresh.
